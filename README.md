# Data-Analysis-Capstone-Project
📊 Bank Loan Report – Data Analytics Project
📌 Project Overview

This project focuses on analyzing and visualizing bank loan data to monitor and assess lending activities, track key metrics, and identify trends that can support data-driven decision-making.

The project uses dashboards to provide insights into:

Loan portfolio performance

Loan repayment trends

Good vs. Bad loans

Borrower demographics and financial health

🎯 Objectives

Build an interactive and comprehensive Bank Loan Report.

Track and monitor Key Performance Indicators (KPIs) for loans.

Identify trends, seasonality, and regional variations in lending activities.

Provide a user-friendly interface for decision-makers to assess loan portfolio health.

📈 Key Performance Indicators (KPIs)
Summary Dashboard

Total Loan Applications (including MTD & MoM trends)

Total Funded Amount (including MTD & MoM changes)

Total Amount Received (cash flow & repayments)

Average Interest Rate (overall & MoM changes)

Average Debt-to-Income Ratio (DTI)

Good Loan vs. Bad Loan KPIs

Good Loans: Fully Paid & Current

% of Good Loans

Total Good Loan Applications

Funded Amount (Good Loans)

Total Received Amount (Good Loans)

Bad Loans: Charged Off

% of Bad Loans

Total Bad Loan Applications

Funded Amount (Bad Loans)

Total Received Amount (Bad Loans)

Loan Status Grid View

Comprehensive loan categorization with KPIs segmented by loan status.

📊 Dashboards
1. Summary Dashboard

Provides a high-level view of KPIs and loan portfolio health.

2. Overview Dashboard (Visual Analysis)

Monthly Trends (Line Chart): Loan Applications, Funded Amount, Amount Received

Regional Analysis (Filled Map): Lending activity by state

Loan Term Analysis (Donut Chart): Loan distribution by term (36/60 months)

Employment Length Analysis (Bar Chart): Loans by borrower employment history

Loan Purpose Breakdown (Bar Chart): Reasons for loan applications

Home Ownership Analysis (Tree Map): Lending patterns by home ownership

3. Details Dashboard

A consolidated, drill-down view of loan data including borrower profiles and repayment details.
